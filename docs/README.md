# Bubot 문서 색인

`docs/`는 목적·명령·규칙·명세 같은 **정본 문서**다. 현재 상태·결정·미결·계획은 `../work-status/`, 과정 기록은 Private Worklog가 소유한다.
역할 구분과 기록 경계는 [DOCUMENTATION.md](DOCUMENTATION.md)가 정본이다.

## 문서

| 문서 | 역할 |
|---|---|
| [PROJECT.md](PROJECT.md) | 목적·영역 경계·기술·안전 경계 |
| [GIT-WORKFLOW.md](GIT-WORKFLOW.md) | 브랜치·PR·merge·릴리즈·CI 규칙 |
| [COMMANDS.md](COMMANDS.md) | 실행·검증 명령 |
| [DOCUMENTATION.md](DOCUMENTATION.md) | 문서 역할·기록 경계·고위험 정본 지도 |
| [AI-STYLE.md](AI-STYLE.md) | AI 답변·Checklist·브리핑 문형 |
